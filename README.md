# Visio 装修平台 —— 移动端页面可视化装修

面向运营/业务人员的移动端 H5 页面可视化装修平台:左侧物料面板、中间手机画布、右侧属性面板,拖拽即所见即所得。

## 功能一览(MVP)

- **页面管理**:新建(空白/示例模板)、编辑、复制、重命名、删除、导出/导入 JSON;**列表卡片直接渲染页面迷你真实缩略图**
- **组件模板**:配置好的组件一键「存为模板」,物料面板「模板」页签随时复用(独立持久化 `visio:templates:v1`)
- **可视化编辑**:物料拖拽入画布、拖拽排序、选中/上移/下移/复制/删除;**画布 40%–100% 缩放**、**撤销历史时间线**(每步带可读标签,点击任意步回跳/重做)、**图层面板拖拽排序**;快捷键:Ctrl+Z / Ctrl+Shift+Z 撤销重做、Ctrl+D 复制、Ctrl+S 保存、Alt+↑/↓ 微调顺序、Delete 删除、Esc 取消选中、Ctrl+K 命令面板
- **图片能力**:图片地址 / 示例图 / **本地文件上传**(Canvas 自动压缩至 750px 宽,dataURL 存入 Schema,无需图床)
- **9 个内置物料**:文本、图片、按钮、分隔线、辅助空白、公告栏、轮播图、魔方栅格、商品卡片(图片/按钮/轮播图/魔方/商品均支持配置跳转链接,预览时新窗口打开)
- **Schema 驱动**:页面即一份 JSON,属性面板由物料的 `propsSchema` 动态生成,新增物料零胶水代码
- **编辑体验**:画布拖拽(悬停视口边缘自动滚动)、面板可折叠、图层管理、最近编辑置顶
- **单元测试**:Vitest 覆盖工具函数与核心 store(`npm run test`)
- **主题一键换肤**:6 套预设主题(极简白/暗夜紫/国潮红/清新绿/海洋蓝/落日橙),按语义槽位重映射页面与组件配色,整页风格瞬间切换,可 Ctrl+Z 撤销
- **页面体检**:规则引擎扫描占位文本、空白图片、缺失链接等问题,点击问题一键定位到画布对应组件
- **命令面板 Ctrl+K**:搜索式快捷入口,添加物料/切换主题/体检/保存/预览全键盘直达
- **实时预览**:编辑与预览共用同一渲染引擎(`/preview/:id`)
- **本地持久化**:localStorage 自动保存,无后端依赖

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
```

## 脚本命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run typecheck` | 仅类型检查(vue-tsc) |
| `npm run lint` / `lint:fix` | ESLint 检查 / 自动修复 |
| `npm run test` / `test:watch` | Vitest 单元测试(34 个用例)/ 监听模式 |
| `npm run format` | Prettier 格式化 |
| `npm run preview` | 预览生产构建 |

## 技术栈

Vue 3.5 · TypeScript(strict)· Vite 6 · Pinia · Element Plus · 原生 HTML5 Drag & Drop

## 目录速览

```
src/
├── shared/          # 类型、常量、工具、页面 Schema 工厂
├── stores/          # Pinia:pages(页面列表)/ editor(编辑器状态与历史)
└── modules/
    ├── home/        # 页面管理列表(/)
    ├── editor/      # 三栏编辑器(/editor/:id)
    ├── preview/     # 预览页(/preview/:id)
    ├── renderer/    # 渲染引擎(编辑/预览共用)
    └── materials/   # 物料注册表 + 各物料(一个物料一个目录)
```
